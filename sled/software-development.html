Software projects agencies can buy and finish

Many agency software needs are small and specific: a resident-facing form, a permit tracker, a website that finally meets accessibility rules. These projects stall because they are too small for large integrators.

Konnex takes them on. We scope tightly, price each phase and build with a hybrid team. You get code you own, documentation and a handover.

Our founder builds production software in React, TypeScript and Supabase, and stays involved in technical decisions.

How we deliver public-sector IT work

Agency data stays in the US. Projects run in US-hosted cloud environments, and our offshore engineers work only on code and synthetic test data. They never access production systems or agency records. Where a contract or state law requires all work in the US, we tell you up front and staff it that way, or we pass.

ADA Title II: the deadline is real

The US Department of Justice requires state and local government websites and apps to meet WCAG 2.1 AA. An interim final rule in April 2026 set the dates below.

ADA Title II web accessibility compliance dates
Public entityCompliance date
Serving 50,000 or more peopleApril 26, 2027
Serving fewer than 50,000 people, and special districtsApril 26, 2028

Source: US DOJ interim final rule, Apr 20, 2026, via Reed Smith.

How a project runs

  1. Scope. A short discovery to agree deliverables, acceptance criteria and data rules.
  2. Fixed phases. Work is split into phases with a price and a deliverable each.
  3. Build and test. Code and synthetic test data only. Agency data stays in US-hosted environments.
  4. Accept and hand over. You review, accept and get the code, documentation and training.

Common questions

For IT directors, CIO offices and procurement. Still unsure? Ask us directly.

Can a government agency hire an offshore software team?

Often yes, for work that does not touch restricted data, such as public websites, code built on synthetic data and testing. Some states and data types require US-only work. Read our guide.

Do you build to Section 508 and WCAG 2.1 AA?

Yes. Accessibility is part of our definition of done, and we test with automated tools and manual keyboard and screen reader checks.

Who owns the code?

You do. Code, documentation and design files are handed over at acceptance.

What stack do you use?

We work in your stack where one exists. For new builds we often use React and TypeScript with a US-region cloud host.

How do you price projects?

Fixed price per phase, after a short scoping step. That keeps many projects under small-purchase thresholds.
